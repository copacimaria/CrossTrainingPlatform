# Architecture Decision Records

Fiecare fisier inregistreaza o decizie de arhitectura: contextul in care a fost
luata, ce s-a decis si ce costa decizia. Scopul nu este documentatia, ci sa nu se
mai reia aceeasi discutie peste sase luni fara sa se stie de ce s-a ales asa.

Un ADR nu se editeaza dupa ce a fost acceptat. Daca decizia se schimba, se scrie
un ADR nou care il marcheaza pe cel vechi ca `Superseded`.
